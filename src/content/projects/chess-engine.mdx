A fully functional chess engine built from scratch in C++, with a graphical interface for playing against it.

## Key Features

- **Bitboard board representation:** O(1) piece lookup and efficient pseudo-legal move generation.
- **Search:** Minimax with alpha-beta pruning and iterative deepening.
- **Heuristic evaluation:** Scores positions to guide the search toward strong moves.
- **SDL2 GUI:** A native window rendering the board, pieces and move highlights.
- **CMake build:** Cross-platform build setup.
