A stateless competitive programming dashboard that lets educators track student performance across platforms without storing any user data.

## Key Features

- **Multi-platform aggregation:** Pulls submission history and stats from Codeforces, LeetCode and HackerRank through their public APIs.
- **CP Wrapped:** Generates a visual annual summary of a student's competitive programming activity.
- **Stateless by design:** No database, so there's no hosting overhead and no student data to protect.
- **Resilient fetching:** Handles rate limits and inconsistencies between the platforms' APIs gracefully.
