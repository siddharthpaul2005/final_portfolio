File Encryptor — CLI/TUI In Development
C++ · libsodium (AES-256-GCM)

A cross-platform command-line and terminal UI tool for file encryption with authenticated encryption.

  • Initially implemented AES-256 from scratch in C++ to understand the cipher at the block level before migrating to libsodium's AES-256-GCM for production use.
  • Custom binary format: encrypted files carry a structured header (magic bytes, version, algorithm ID, nonce, tag) so they're self-describing and portable.
  • Designed for single-binary deployment on Linux, macOS, and Windows.
